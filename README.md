# Ne Kadar Büyük?

Haberlerde geçen 1, 2 ve 20 milyar TL'nin gündelik hayattaki yaklaşık karşılıklarını gösteren etkileşimli Streamlit uygulaması.

## Yerelde çalıştırma

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Streamlit Community Cloud

- Repository: `veridelisi/ne-kadar-buyuk`
- Branch: `main`
- Main file path: `streamlit_app.py`

Uygulamadaki fiyat ve maliyetler `streamlit_app.py` dosyasının başındaki `BENCHMARKS` listesinde tutulur.
